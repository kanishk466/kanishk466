### 🤖 Multi-Agent Customer Support System &nbsp;![status](https://img.shields.io/badge/status-building-2C5364?style=flat-square)

A live chat support system where a **Router Agent** classifies each customer message and
dispatches it to a specialist agent **(tech / billing / sales)** that answers via **RAG**
over company docs — with automatic **ticket handoff** when confidence drops.

<img src="https://img.shields.io/badge/NestJS-E0234E?logo=nestjs&logoColor=white&style=flat-square" /> <img src="https://img.shields.io/badge/Socket.IO-010101?logo=socketdotio&logoColor=white&style=flat-square" /> <img src="https://img.shields.io/badge/LangGraph-1C3C3C?logo=langchain&logoColor=white&style=flat-square" /> <img src="https://img.shields.io/badge/Qdrant-DC2440?logo=qdrant&logoColor=white&style=flat-square" /> <img src="https://img.shields.io/badge/Redis-FF4438?logo=redis&logoColor=white&style=flat-square" /> <img src="https://img.shields.io/badge/PostgreSQL-4169E1?logo=postgresql&logoColor=white&style=flat-square" />

- **RAG** over company docs — every reply shows *agent, intent, confidence, reason &amp; sources*

- **5 components, every one optional** — runs with zero API keys and zero databases

### 📄 PDF Q&amp;A System (RAG) &nbsp;![status](https://img.shields.io/badge/status-live-2C5364?style=flat-square)

Upload a PDF, ask questions in plain language, get answers with **page-level citations** —
with background ingestion via a BullMQ queue and progressive status polling.

<img src="https://img.shields.io/badge/Fastify-2C5364?style=flat-square" /> <img src="https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white&style=flat-square" /> <img src="https://img.shields.io/badge/OpenAI-412991?logo=openai&logoColor=white&style=flat-square" /> <img src="https://img.shields.io/badge/Pinecone-2C5364?style=flat-square" /> <img src="https://img.shields.io/badge/BullMQ-FE0902?style=flat-square" /> <img src="https://img.shields.io/badge/PostgreSQL-4169E1?logo=postgresql&logoColor=white&style=flat-square" />

- **Recursive chunking** (500 tokens / 50 overlap) packed greedily, tracking page numbers
- **Background ingestion** with BullMQ + Redis — upload returns `202`, poll until `ready`
- Answers cite **page ranges with similarity scores**, plus the raw retrieved chunks
- **Zero-key offline mode**: local embeddings, in-process vector store, extractive answers
